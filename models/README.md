# Models Directory

This directory stores trained PyTorch model weights for the **Signature Forgery Detector**.

- `siamese_model.pt`: Saved PyTorch `state_dict` generated by running `python src/train.py`.
- Model Architecture: `SiameseNet` with `EmbeddingNet` (128-dimensional output embedding).

To generate new model weights, run:
```bash
python src/train.py --epochs 15 --batch-size 16 --lr 0.001
```
